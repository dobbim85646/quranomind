# QuranoMind (المصباح الوهّاج) - Android Application

تطبيق أندرويد إسلامي شامل ومتقدم لتفسير القرآن الكريم وفهم آياته وتدبرها، تم تطويره باستخدام **Kotlin** و **Jetpack Compose** و **Material Design 3**.

---

## 🌟 الميزات الرئيسية (Core Features)

1. **تفسير القرآن والآيات (Quran Ayah & Tafsir Explorer):**
   - استعراض جميع سور القرآن الـ 114 بالاسم العربي والإنجليزي ورقم السورة ونوع النزول (مكية / مدنية).
   - اختيار أي آية من 1 إلى آخر آية في السورة مع أزرار التنقل السريع والسلس.
   - دعم مناهج تفسير متعددة:
     - التفسير الميسر (محلي وغير متصل بالإنترنت + دعم الذكاء الاصطناعي).
     - تفسير القرآن العظيم للإمام ابن كثير.
     - الجامع لأحكام القرآن للإمام القرطبي.
     - تيسير الكريم الرحمن للشيخ السعدي.
     - مقارنة منهجية بين المفسرين الثلاثة (ابن كثير، القرطبي، السعدي).
     - تدبر إيماني وفهم شامل عبر الذكاء الاصطناعي (Gemini).
   - دعم ثنائي اللغة: التفسير بالعربية وترجمة معاني التفسير بالإنجليزية.
   - نطق صوتي للآيات والتفاسير (Text-to-Speech) مدمج.

2. **الكون والإعجاز العلمي (Cosmic Signs & Quranic Science):**
   - استعراض وشرح الكلمات والظواهر الكونية المذكورة في القرآن (مثل: الخنس، الكنس، الطارق، النجم الثاقب) ومقارنتها باكتشافات الفيزياء الفلكية الحديثة (كالثقوب السوداء والنجوم النابضة).
   - استعراض الآيات العلمية وشرحها البيولوجي والجيولوجي والكوني.

3. **تفسير الرؤى والأحلام بضوابط الشريعة (Islamic Dream Interpretation):**
   - إدخال وصف الرؤيا مع تحديد جنس الرائي (ذكر / أنثى).
   - تحليل الرموز واستنباط البشارات والتوجيه الإيماني وفق ضوابط التعبير الإسلامية وآدابها.

4. **البحث في التفاسير والموضوعات الإسلامية (Search Across Tafasir & Topics):**
   - محرك بحث في جميع ملفات التفسير المتاحة محلياً مع عرض الآيات المطابقة ومقتطف التفسير.
   - دعم البحث الموضوعي المعمق بالذكاء الاصطناعي عند عدم توفر نتائج محلية.

5. **المفضلة والمحفوظات (Favorites & Bookmarks):**
   - حفظ أي آية وتفسيرها في المفضلة المحلية بنقرة واحدة.
   - إمكانية نسخ النص إلى الحافظة، الاستماع الصوتي، وحذف الآيات المحفوظة.

6. **فهرس السور الشامل (Comprehensive Surah Index):**
   - قائمة منظمة بجميع سور القرآن الـ 114، مع عدد الآيات، مكان النزول، والاسم المعرب والمترجم.

7. **التصميم والواجهة (Design & Modern Experience):**
   - تصميم إسلامي فاخر مستوحى من الخط والمخطوطات العربية مع لوحة ألوان كحلية وذهبية وزمردية.
   - دعم الوضع الداكن (Dark Mode) والوضع الفاتح (Light Mode).
   - دعم التوجيه من اليمين لليسار (RTL) للغة العربية ومن اليسار لليمين (LTR) للإنجليزية.

---

## 🛠 التقنيات المستخدمة (Tech Stack)

- **Language:** Kotlin 2.2
- **UI Framework:** Jetpack Compose (Material Design 3)
- **Architecture:** MVVM (Model-View-ViewModel) + Repository Pattern
- **Persistence:** SQLite Database via Android OpenHelper + Flow
- **Audio:** Native Android TextToSpeech (Arabic & English)
- **AI Integration:** Google Gemini API (`gemini-3.5-flash`) via Secrets Gradle Plugin
- **Build System:** Gradle Kotlin DSL (`build.gradle.kts`) with AGP 9.1.1
